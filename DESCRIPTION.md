# Description

A square wheel can glide with a level axle on a road made of inverted catenary arches. But level motion and constant speed are different properties. This experiment compares two clocks, checks why a triangle fails despite satisfying the local contact formula, and explores an ideal energy-conserving square. Includes reproducible Python code, numerical illustrations and explicit limits. Inspired by Slavik and Wagon's *A Minimalist Approach to Rolling Wheels* (arXiv:2604.03749v3).
